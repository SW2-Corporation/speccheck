# Proposal: Sistema di Biglietteria Online Cinema

## Motivazione
Permettere agli spettatori registrati di consultare le proiezioni disponibili, scegliere la poltrona in sala e acquistare i biglietti online, riducendo le code alle casse fisiche del cinema.

## Ambito (Scope)
- Autenticazione degli utenti registrati tramite email e password.
- Consultazione delle proiezioni programmate con conteggio delle poltrone libere.
- Selezione della poltrona e calcolo del prezzo base.
- Pagamento elettronico tramite gateway esterno ed emissione del biglietto con invio codice via SMS.
- Annullamento dei biglietti acquistati fino a 2 ore prima dell'inizio della proiezione.
