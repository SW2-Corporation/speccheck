# UC3 Svuotare la lista

- **Attore principale**: utente.
- **Precondizioni**: la lista contiene almeno un prodotto.
- **Postcondizioni**: la lista è vuota.

## Scenario principale
1. L'utente chiede di svuotare la lista.
2. Il sistema chiede conferma.
3. L'utente conferma.
4. Il sistema toglie tutti i prodotti.

## Estensioni
- 3a. L'utente annulla: la lista resta com'era.
